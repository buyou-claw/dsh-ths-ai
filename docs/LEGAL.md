## 2. 技术方式（我们做什么）

- 在**你本人的电脑上**启动一个浏览器（默认系统 Edge），使用**你本人已登录**的浏览器 profile 访问问财网页；
- 读取页面上你本来就能看到的表格文本，交给 DSH 里的模型做整理；
- 所有环节都在本机完成：**没有服务端、没有 API Key、没有账号密码上传、没有数据外发**；
- 登录动作由**你本人**在可见窗口中完成，项目不接触你的密码或验证码。

## 3. 合规边界（我们刻意不做什么）

| 边界 | 本项目的做法 |
|---|---|
| 反检测/伪装 | **不内置任何隐身参数**（0.1.0 已移除 `--disable-blink-features=AutomationControlled`） |
| 登录/验证码 | 不绕过、不代答、不接打码服务 |
| 付费内容 | 不绕过付费墙或会员限制 |
| 批量采集 | 不含爬虫框架、不含并发调度、不含代理池/IP 轮换 |
| 访问频率 | 默认两次查询间隔 **≥3 秒**，且只有你手动发问才会触发 |
| 数据留存 | 不建立行情数据库、不缓存结果到磁盘、不二次分发 |

- 自动化访问网页**可能被站点判定为违反其用户协议**，即使频率很低。这是本项目的**固有风险**，不是配置问题。
- 问财前端随时可能改版，导致解析失效；本项目不承诺持续可用。
- 页面内容的准确性、完整性和时效性由同花顺/问财负责，本项目不做任何校验。
- 模型整理结果**可能出错**（数字、日期、口径都可能被误读）。任何决策前请回到原始页面核对。

## 7. 隐私与数据

| 数据 | 位置 | 说明 |
|---|---|---|
| 登录 Cookie（含 `u_ukey`） | `<插件目录>/profile/`（或 `DSH_THS_PROFILE_DIR`） | 只在本机；已加入 `.gitignore`；删除该目录即退出登录 |
| 诊断日志 | `~/.dsh/logs/dsh-ths-ai.log` | 只记录事件与错误信息（不含 Cookie 值）；超过 512 KB 自动清空 |
| 查询内容 | 仅存在于内存与 DSH 会话中 | 不落盘、不上传 |

本机上的插件**不会**把你的数据发送给项目作者或任何第三方。但请注意：你使用的 DSH 模型服务本身有自己的数据处理条款，那由 DSH/模型提供方决定，与本项目无关。
