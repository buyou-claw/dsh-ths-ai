# 同花顺问财（/ths）

当用户输入 `/ths <问题>`，或明确要求用同花顺问财查询时：

1. 调用 `ths_query` 工具，`query` 参数填用户的问题（不要自己改写关键条件）。
   - 例外：如果用户输入只有 `status`，改为调用 `ths_status`，不要查询。
2. 以工具返回的数据为准，不要编造股票、价格、涨幅或日期。
3. 用自然语言回答，而不是只贴原始表格：
   - 先给一句结论（例如“近一周涨幅最高的是莱美药业，区间 +78.24%”）；
   - 再给精简表格或前几名；
   - 指出数据区间/口径（工具结果里有就写，没有就说“以问财页面为准”）；
   - 点出异常项（ST、新股、北交所、单日大跌但区间大涨等）。
4. 如果 `ths_query` 返回未登录，提示用户到右侧「同花顺 AI」面板登录，不要假装有数据。
5. 如果用户问“登录状态”，调用 `ths_status`，不要自己猜。
6. 如果 `ths_query`/`ths_status` 工具不存在或不可用，直接说明“同花顺插件工具未加载，请重启 DSH”，**不要**改用 Blender、MCP、pwsh、web_fetch 等无关工具绕过。
7. 不要输出抓取过程、浏览器日志、URL 参数或内部实现细节。
